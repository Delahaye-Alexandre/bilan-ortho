# Bilans de référence — amorces de style

Ces fichiers sont des **bilans entièrement fictifs** (patients, scores et
contextes inventés), rédigés pour servir d'**amorces de style** : importez-les
depuis l'interface (« Mes bilans de référence ») pour que l'assistant dispose
d'exemples de rédaction clinique dès le premier jour.

**La vraie valeur vient de vos propres bilans** : importez vos PDF ou fichiers
texte (les PDF scannés nécessitent Tesseract) et l'IA s'inspirera de *votre*
style — tournures, niveau de détail, plan. Vous pouvez ensuite supprimer ces
amorces fictives depuis l'interface.

Aucune trame d'auteur tierce n'est redistribuée ici : la structure suit le
tronc commun réglementaire (arrêté du 25/07/2023), rédaction originale.

| Fichier | Domaine à choisir à l'import |
|---|---|
| `bilan-fictif-langage-ecrit.txt` | Langage écrit (lecture / orthographe) |
| `bilan-fictif-langage-oral.txt` | Langage oral |
| `bilan-fictif-voix.txt` | Voix |
| `bilan-fictif-neuro-acquise.txt` | Neurologie acquise |
